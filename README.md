# 💖 Do You Love Me?

An interactive romantic webpage built with **HTML, CSS, and Vanilla JavaScript** featuring beautiful animations, playful interactions, and a fun proposal experience.

Perfect for surprising your partner, sending to your crush, or simply exploring creative frontend animations.

---

## ✨ Preview

> **"Do you love me?"** 💕

The page starts with a cute question where the **YES** button is easy to click...

...but the **NO** button has other plans. 😈

Once **YES** is clicked, the page celebrates with confetti, floating hearts, sparkles, music, and a romantic success screen.

---

## 🌟 Features

❤️ Beautiful animated glassmorphism UI

💖 Floating heart background (Canvas Animation)

✨ Mouse trail hearts

🌸 Sparkle particle effects

🎭 Cute rotating emoji sticker

🎯 Smart escaping **NO** button

📱 Fully responsive for desktop & mobile

🎉 Confetti celebration

🎵 Built-in romantic background music (generated with the Web Audio API)

💍 Romantic success screen

🌈 Animated gradient background

🦋 Smooth transitions and modern animations

---

## 🛠️ Built With

* HTML5
* CSS3
* Vanilla JavaScript
* Canvas API
* Web Audio API

No frameworks.
No libraries.
No dependencies.
